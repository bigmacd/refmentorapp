# PWA Icons

Place your app icons here:

- **icon-192.png** - 192×192 pixels (required for Android)
- **icon-512.png** - 512×512 pixels (required for splash screen)

You can generate these from a single high-resolution source image (e.g. 512×512) using an image editor or online tool like [realfavicongenerator.net](https://realfavicongenerator.net/) or [pwa-asset-generator](https://github.com/onderceylan/pwa-asset-generator).
